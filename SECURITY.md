# Security policy

## Supported versions

Only the latest commit on the `main` branch is supported. Fixes are not backported.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email **tahmidbintaslimrafi@gmail.com** with:

- a description of the problem and its impact,
- steps or a proof of concept to reproduce it,
- the commit or URL you tested.

You can also use GitHub's [private vulnerability reporting](https://github.com/tahmidbintaslim/Clock-Weather-App/security/advisories/new) if it is enabled for this repository.

This is a personal project maintained in spare time, so there is no guaranteed response time. You will get a reply once the report has been read, and credit in the fix if you want it.
